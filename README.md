# Salesforce QE Bootcamp

Mobile-first React/Vite PWA for Salesforce Quality Engineer interview preparation. It contains 120+ generated practice exercises across QA, Python/pytest, Git/GitHub, CI/CD, Salesforce, Apex, Playwright, APIs, SFDX, quality strategy, interview practice and capstone scenarios.

## Run
npm install
npm run dev

## Build
npm run build

## iPhone
Deploy the `dist` folder to an HTTPS static host. Open the URL in Safari on iPhone → Share → Add to Home Screen. The PWA manifest and service worker are already included.
